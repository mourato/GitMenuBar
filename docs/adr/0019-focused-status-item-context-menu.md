# ADR 0019: Focused status-item context menu

Status: Accepted
Date: 2026-10-12

Keep only AI Usage Quotas (when enabled), Settings, and Quit in the status-item
context menu; Git and project actions remain available in their existing app
surfaces. This supersedes ADR 0018's decision to retain Git commands in the
quota menu while preserving its status-item ownership, click behavior, and quota
data and presentation decisions.

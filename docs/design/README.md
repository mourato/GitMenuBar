# Design references

Static mockups that show intent. They are not pixel specs: `docs/ui.md` and the
Workbench tokens win when they differ.

- `commit-inspector-2026-10-29.png`: commit details as a split side panel.
  Known differences from the contract: menu labels in the image end with an
  ellipsis (not allowed in the app); "Open on GitHub" is shown in accent but
  uses the Secondary style; the orange pills are review notes, not UI; the
  inspector card has a shadow in the image but the split panel has none.
  Plans: `advisor-plans/commit-inspector-2026-10-29/`.

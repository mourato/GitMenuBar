# Premium UI references

Fictional, standalone HTML mockups and rendered PNGs for the approved backlog.
These show intent; native macOS controls and Workbench tokens govern implementation.
The issue acceptance criteria override illustrative details in a mockup.
No application code changes are included.

- `codex-header`: single provider header, no overlap.
- `sidebar`: approved icon-only colors and stable count columns.
- `overview`: Issues before Pull Requests, quiet empty values and active panel feedback.
- `quotas`: detailed cards always use continuous meters with pace.
- `menubar`: compact Line option; preserve existing style preferences.
- `footer`: critical window with an explicit percentage.

Each PNG is rendered from the HTML of the same name in headless Chrome.
HTML files have no remote dependencies. Provider symbols are placeholders,
not replacement app icons. Headers and explanatory captions are reference annotations.
